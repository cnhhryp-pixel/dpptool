How it works

The validator screens an identifier for a simple machine-friendly format. It flags spaces, very long values and characters that can create problems when identifiers are embedded in URLs or exchanged between systems.

DPP context

Frequently asked questions

What does this DPP Identifier Validator check?

It checks basic syntax hygiene such as length, spaces, reserved URL characters and a machine-friendly character set.

Does it prove an identifier is globally unique?

No. The tool cannot confirm ownership, global uniqueness or compliance with a specific identifier standard.

Why should identifiers stay stable?

A stable identifier helps preserve the connection between the physical product, its passport, Registry metadata and downstream systems even when presentation pages change.
