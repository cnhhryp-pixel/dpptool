## Action rules

### If indexed but impressions are near zero
- Improve internal links from stronger pages.
- Expand search-intent coverage.
- Recheck title/H1 alignment.
- Wait for data before creating more pages.

### If impressions rise but CTR is low
- Rewrite title and meta description.
- Make the benefit/task clearer.
- Preserve the primary keyword.

### If position is 8–20
- Add internal links from relevant pillar pages.
- Improve examples, FAQs, official sources and tool usefulness.
- Avoid creating a competing page for the same intent.

### If two pages rank for the same query
- Decide which page should be primary.
- Strengthen the preferred page.
- Reduce overlapping wording on the secondary page.

### If a tool gets impressions
- Prioritise tool usability and speed.
- Add examples and relevant related tools.
- Do not hide the working tool behind signup.

## Initial review cadence
- Week 1–2: indexing coverage and crawl issues
- Week 3–4: first impression/query patterns
- Month 2: CTR and page-group winners
- Month 3: expand sectors/languages based on real demand

## Important
Do not judge SEO performance from the first few days. Use Search Console data to decide which DPP topics, tools, sectors and languages deserve the next development cycle.
