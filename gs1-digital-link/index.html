GS1 Digital Link and the Digital Product Passport.

A web-resolvable identifier can help connect a product to digital resources, but DPP compliance still depends on the applicable EU product rules.

What it can help with

Digital Link can make existing product identifiers resolvable on the web so a scan can lead to the relevant digital resource.

What it does not solve by itself

  • It does not define sector-specific DPP fields.
  • It does not decide model, batch or item level.
  • It does not replace Registry obligations.
  • It does not automatically create access-control or long-term hosting policies.
Use open, interoperable standards. ESPR requires DPP data to avoid vendor lock-in.

How GS1 Digital Link fits into a DPP architecture

GS1 Digital Link provides a standards-based way to express GS1 identification keys in web URIs. That can let a QR code or other data carrier resolve to product information while preserving an identifier that is meaningful across supply-chain systems.

Example architecture

GS1 identifier → Digital Link URI → resolver → DPP resource / product information

Why resolver design matters

  • The identifier should remain stable even if hosting changes
  • The resolver can route different users to different digital resources
  • Product data should remain exportable and interoperable
  • Marketing content and regulatory passport data should not be confused

Not mandatory for every DPP

GS1 Digital Link can be useful where GS1 identifiers are already used, but the EU DPP framework does not mean every product must use the same identifier or resolver standard. Product-specific legal and technical rules still govern the implementation.
