How it works

Enter a full HTTPS base URL and a persistent product identifier. The tool URL-encodes the identifier and appends it to the base path.

Example

Base: https://example.com/dpp/ ID: PROD-2026-001 Result: https://example.com/dpp/PROD-2026-001

Resolver design principles

  • Keep the product identifier stable
  • Use HTTPS
  • Allow the destination content to evolve without changing the identifier
  • Keep the resolver independent from marketing campaign URLs
  • Plan redirects and service-provider exit before large-scale printing

GS1 Digital Link

GS1 Digital Link defines how GS1 identification keys can be represented in web URIs and resolved to related information or services. It can be relevant where GS1 identifiers are used, but it is not a universal requirement for every DPP.

Frequently asked questions

What does the DPP Link Builder create?

It creates a clean resolver-style URL by combining a base URL with an encoded product identifier.

Is the generated URL automatically a compliant DPP link?

No. Compliance depends on the applicable identifier, data-carrier, data, access and Registry requirements.

Can I use GS1 Digital Link?

GS1 Digital Link is one standards-based approach for representing GS1 identifiers in web URIs and resolving them to online information or services.
