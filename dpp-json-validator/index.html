How it works

The tool first parses your text as JSON. If parsing succeeds, it inspects either the product object or the top-level object for starter fields such as name, SKU, GTIN, manufacturer, country of origin and materials.

Try a simple example

Frequently asked questions

What does the DPP JSON Validator validate?

It checks whether the text is valid JSON and then looks for a small starter set of common product-data fields.

Is this an official EU DPP schema validator?

No. There is no single universal DPP schema for every product group. Final schemas depend on applicable legislation, standards and sector-specific data models.

Why use JSON for DPP data?

JSON is a common machine-readable format for APIs and data exchange, making it useful for internal preparation and system integration.
