# DPPTool

Static-first Digital Product Passport tools and EU compliance knowledge base for **dpptool.com**.

## V1
- Digital Product Passport checker
- DPP draft generator (runs locally in the browser)
- Battery Passport guide
- DPP requirements guide
- ESPR overview
- Sector priority hub
- SEO essentials: sitemap, robots, canonical tags, structured data
- Cloudflare Pages headers

## Deployment
Designed for GitHub -> Cloudflare Pages. No build command is required. Publish the repository root.

## Important
DPPTool provides practical compliance guidance, not legal advice. Product-specific obligations depend on applicable EU legislation and delegated acts.
