How the DPP Draft Generator works
The form converts basic product information into a portable JSON object with a product section, compliance notes, a timestamp and a clear disclaimer. The preview updates in the browser before download.
Example output structure
{
  "@type": "Product",
  "product": {
    "name": "Example Product",
    "sku": "SKU-001",
    "gtin": "4006381333931",
    "manufacturer": "Example Manufacturer",
    "countryOfOrigin": "DE",
    "materials": ["aluminium", "PP"]
  },
  "compliance": {
    "notes": "Reference technical documents here"
  }
}
What to do with the draft

Frequently asked questions
What does the DPP Draft Generator create?
It creates a simple JSON product-data draft from the information you enter and lets you download it locally.
Is the downloaded JSON an official Digital Product Passport?
No. It is a starter data draft for preparation and system design. Final DPP fields, schemas and access requirements are product-specific.
Is my product data uploaded to DPPTool?
No. In this static version the form is processed in your browser and the JSON file is created locally.
